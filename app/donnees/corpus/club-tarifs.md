# Tarifs et formules du club

## Cotisations annuelles par discipline

Tous les tarifs sont annuels et incluent la licence fédérale (affiliation à la
fédération). Pour les personnes qui n'habitent pas Châtillon (hors commune), il
faut ajouter 20 € à chaque tarif.

Kick-boxing : 320 € par an. Étudiant : 270 €. Hors commune : 340 €. Étudiant hors commune : 290 €.
Muay Thaï : 320 € par an. Étudiant : 270 €. Hors commune : 340 €. Étudiant hors commune : 290 €.
MMA : 380 € par an. Étudiant : 330 €. Hors commune : 400 €. Étudiant hors commune : 350 €.
MMA Enfant (8-15 ans) : 270 € par an. Hors commune : 290 €.
Kids (8-12 ans) : 200 € par an. Hors commune : 220 €.
Ados (12-17 ans) : 230 € par an. Hors commune : 250 €.
Cardio Boxing : 230 € par an. Hors commune : 250 €.
Cross Training Boxe : tarif à voir avec le secrétariat (réservé aux adhérents).

## Formules multi-disciplines

Kick-boxing + Muay Thaï : 450 € par an. Étudiant : 370 €. Hors commune : 470 €. Étudiant hors commune : 390 €.
MMA + Kick-boxing ou Muay Thaï : 490 € par an. Étudiant : 410 €. Hors commune : 510 €. Étudiant hors commune : 430 €.
MMA + Kick-boxing + Muay Thaï : 510 € par an. Étudiant : 430 €. Hors commune : 530 €. Étudiant hors commune : 450 €.
Cardio Boxing + Kick-boxing ou Muay Thaï : 380 € par an. Étudiant : 340 €. Hors commune : 400 €. Étudiant hors commune : 360 €.

## Formules avec le MMA Enfant

Boxe Kids (8-12 ans) + MMA Enfant : 370 € par an. Hors commune : 390 €.
Boxe Ados (12 ans et plus) + MMA Enfant : 390 € par an. Hors commune : 410 €.

## Bon à savoir sur le paiement

Le tarif étudiant est accordé sur justificatif. Pour les aides, le club accepte
uniquement le PASS92. Il est possible de payer en plusieurs fois ou de demander
un encaissement ultérieur.
